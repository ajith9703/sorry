# Sorry Aaru - Premium Romantic Website

## Project Structure
- index.html (main entry)
- css/style.css (core styles)
- css/animations.css (animation styles)
- js/script.js (main JS)
- js/animations.js (GSAP/AOS)
- js/music.js (audio player)
- js/particles.js (particle effects)
- js/gallery.js (photo gallery)
- js/timeline.js (memory timeline)
- js/games.js (mini games)
- js/effects.js (falling effects, cursor, fireworks)
- assets/ (images, gifs, icons)
